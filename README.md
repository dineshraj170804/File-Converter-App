# 📄 File Converter App

A simple and efficient Flutter application that converts images into PDF files with built-in file opening and sharing functionality.

---

## 🚀 Features

✅ Image Upload  
✅ Convert Images to PDF  
✅ Save Converted PDF  
✅ Open PDF Directly  
✅ Share PDF Instantly  
✅ Clean and Responsive UI  
✅ Cross-Platform Flutter App  

---

## 📱 App Overview

The File Converter app allows users to:

- Select image files
- Convert images into PDF documents
- Save generated PDFs locally
- Open PDFs directly
- Share converted PDFs easily

## 🔥 How the App Works

### 1. Upload Image
Users select an image using File Picker.

### 2. Convert to PDF
The image is converted into a PDF document using the Flutter PDF package.

### 3. Save File
Generated PDFs are stored locally using Path Provider.

### 4. Open PDF
Users can instantly preview converted PDFs.

### 5. Share PDF
The app supports sharing generated PDFs using device share options.
